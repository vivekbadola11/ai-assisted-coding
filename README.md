# AI-Assisted Coding: course files

| Folder | What it is |
|---|---|
| `shoplite/` | The practice project. Open **only this folder** in Claude Code or Cursor. |
| `labs/` | Lab sheets, prompts and checks for each topic. Keep it next to `shoplite/`. |

## Get the course

```bash
git clone https://github.com/vivekbadola11/ai-assisted-coding.git
cd ai-assisted-coding/shoplite
```

Or unzip `AI_Assisted_Coding_course.zip`. You get the same `ai-assisted-coding/` folder.

Start with `shoplite/README.md`, then `labs/01-setup/README.md`.

Some labs include checks the agent mustn't read, such as
`labs/02-prompting/check-shop-113.mts`. Run them from inside `shoplite/`:

```bash
node ../labs/02-prompting/check-shop-113.mts
```
